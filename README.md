# 🌍 True Travel – MERN Stack Project

## 📌 Overview
True Travel is a full-stack travel platform designed to help users discover, share, and manage travel destinations and accommodations in one place.

It is a **community-driven application** where users can explore listings, create their own travel posts, and book trips.

---

## ✨ Key Features

- 🔐 User Authentication (Signup/Login using JWT)
- 🏞️ Browse travel destinations and listings
- ➕ Create, update, and delete listings (CRUD operations)
- 📄 Detailed view page for each listing
- 📱 Responsive UI for all devices
- 🧾 Form validation (minimum 150 character description)
- 🖼️ Default image handling for listings
- 🌱 Database seeding (bulk sample data initialization)

## ⚠️ Challenges Faced

- MongoDB connection timing issues
- Wrong working directory caused old code execution
- Silent validation failures due to missing error handling
- Route conflicts (route overwriting problem)
- File handling and data consistency issues

---

## 📚 Key Learnings

- Always connect database before starting server
- Use `try-catch` in async routes for proper error handling
- Ensure correct working directory before running project
- Use POST instead of GET for data creation
- Modular structure improves scalability and debugging
